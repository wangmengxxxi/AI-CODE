雁山文脉

资中古称“资阳”，因“资水（沱江）之阳”得名。我校扎根雁山沱水之间，以“雁山书院”为精神原乡——

  • · 雁山讲坛：每月名家讲座，涵养人文底蕴
  • · 沱江诗社：学生原创诗词集《雁声集》连续出版12年
  • · 雁阵计划：拔尖创新人才培养体系，近五年获奥赛国家奖47人次
