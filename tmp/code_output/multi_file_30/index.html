扎根中国大地，服务交通强国

西南交通大学肇始于1896年山海关北洋铁路官学堂，是中国第一所工程教育高等学府，素有“东方康奈尔”美誉。1931年迁址唐山，1972年定址成都，形成犀浦主校区（现代化智慧校园）、九里校区（历史文脉核心区）、峨眉校区（生态人文实践基地）三校区协同发展格局。

学校以“交通”为名，以“工科”为基，构建起以交通运输工程（A+）为龙头，土木工程（A-）、电气工程（A-）、机械工程（B+）、信息与通信工程（B+）为骨干的学科生态体系，深度参与京张高铁、川藏铁路、磁浮交通等国家重大工程科技攻关。

2025本科招生政策详解

招生类型

  • 普通高考（含国家专项、高校专项、民族班）
  • 高水平运动队（田径、游泳、篮球）
  • 外语类保送生（限教育部指定外国语中学）
  • 港澳台侨联招、对港免试招生

录取规则

  • 平行志愿省份：专业志愿“分数优先”，无专业级差
  • 顺序志愿省份：专业志愿“志愿优先”，同分比较数学/英语/理综
  • 中外合作办学（利兹学院）：单设院校代码，英语单科≥110分

特色培养

  • “茅以升学院”：本硕博贯通培养（全国Top 1%）
  • “詹天佑班”：轨道交通卓越工程师计划
  • “国际创新学院”：全英文授课，100%海外研修机会
