百年交大 · 薪火相传

历史沿革

肇始于1896年山海关北洋铁路官学堂，是中国近代史上最早的高等学府之一。1900年迁址唐山，1972年定址成都，2000年划归教育部直属。128年办学历程，见证中国铁路从蒸汽机车到智能高铁的全部跨越。

办学定位

以工见长、理工交叉、工管文医协同发展；聚焦“交通强国”“制造强国”国家战略，建成轨道交通领域世界第一的高水平研究型大学。

王牌专业 · 行业引领

交通运输类（含交通运输、交通工程、物流工程）

国家级特色专业，支撑中国高铁智能调度系统、城市轨道交通全自动运行（FAO）核心技术研发。

⚙️

机械类（含车辆工程、机械设计制造及其自动化）

“复兴号”核心部件联合攻关单位，拥有高速列车数字化仿真平台与国家工程实验室。

📡

电子信息类（含通信工程、自动化、人工智能）

服务国家轨道交通信号与控制系统（CTCS）、智能运维AI诊断平台建设。

🏗️

土木类（含铁道工程、桥梁与隧道工程）

川藏铁路、京张高铁等超级工程关键技术支撑单位，世界最大规模轨道结构实验室。

五育并举 · 卓越成长

“詹天佑班”“茅以升班”本硕贯通培养

选拔前10%学生，配备院士/杰青导师，实行“课程+科研+实践”三阶段进阶式培养。

轨道交通现场教学体系

在成都动车段、重庆北站、成灌线等真实场景开展《列车运行控制》《轨道检测技术》等课程教学。

国际联合实验室与双学位项目

与英国利兹大学（Transportation）、美国佐治亚理工（Civil Engineering）等12所高校共建实验室，提供“2+2”“3+1+1”本硕连读通道。

三校区 · 一脉相承

现代化智慧校园

占地约3000亩，拥有现代化图书馆（藏书400万册）、轨道交通国家实验室、大学生创新创业中心（国家级众创空间）、全光网络覆盖、人脸识别门禁系统。毗邻成都地铁6号线“西南交大站”，通勤便捷。

百年文脉承载地

始建于1920年代，现存“红楼”“明诚堂”等历史建筑群，为全国重点文物保护单位。现为艺术与传播学院、国际教育学院所在地，中西合璧建筑风格与深厚人文底蕴交融。

山水园林式校区

坐落于峨眉山麓，依山而建，绿荫如盖。承担大一新生通识教育与基础课程教学，实行小班化、导师制、书院制（“扬华书院”），注重人格养成与学术启蒙。

2025本科招生政策详解

面向全国31个省（区、市）招生，总计划约6500人。四川本地投放计划占比约28%，同时大幅增加中西部省份、民族地区、乡村振兴重点帮扶县专项计划。

平行志愿省份：专业录取采用“分数优先，遵循志愿”原则，无专业级差；对进档考生，按投档成绩从高到低排序，依次满足其专业志愿；投档成绩相同时，依次比较语文、数学、外语成绩。

● 高校专项计划（“筑梦计划”）：面向边远、原贫困、民族等地区县（含县级市）以下高中勤奋好学、成绩优良的农村学生。
● 外语类保送生：限符合教育部规定条件的优秀外国语中学推荐学生。
● 艺术类（设计学类）：使用各省统考成绩，文化分达一本线60%即予投档。

普通本科：4920–6600元/年（按专业不同）；中外合作办学：65000元/年。设立“竢实扬华奖学金”（最高20000元/年）、国家奖助学金、勤工助学岗、基层就业学费补偿等全链条资助体系，确保“不让一个学生因家庭经济困难而失学”。

重要提醒：我校从未委托任何中介机构或个人进行招生录取工作，所有招生信息均以西南交通大学本科招生网（zsw.swjtu.edu.cn）和省级教育考试院公布为准。
