一所扎根巴蜀的文化学府

文脉传承

校址毗邻杜甫草堂与金沙遗址，校内设「锦城书院」，开设《蜀学经典导读》《川剧身段与美育》等校本课程，让千年文脉浸润少年心田。

科创融合

拥有西南首个中学「AI+生态实验室」及「锦江水文监测站」，学生连续三年获全国青少年科技创新大赛一等奖，专利授权量居全省前列。

五育并举

「银杏成长计划」覆盖德智体美劳：每日晨读《论语》选章、每周「锦江毅行」、每月「非遗工坊」、每年「三星堆研学季」，知行合一，身心共长。

2025年招生指南

小学升初中（面向成都市户籍及符合条件随迁子女）

  • 招生计划：4个班，每班45人（含特长生30人）
  • 报名时间：2025年4月10日—4月25日（成都市义务教育招生入学服务平台）
  • 综合评价：注重思维品质、人文素养与实践能力，含「锦城小讲坛」（主题演讲）、「银杏探究日」（小组课题）
  • 特别说明：设立「蜀光奖学金」，对家庭经济困难但品学兼优者全额资助。

初中升高一（中考成绩+校本能力评估）

  • 统招线：2024年参考线：628分（含政策加分）
  • 自主招生：面向科创、人文、艺术特长生，5月举行「锦城学术日」现场评估
  • 课程优势：国家课程校本化 + 「天府青年科学院」项目制学习 + 清华大学「强基计划」衔接课程

国际课程班（AP/A-Level双轨）

  • 语言要求：英语能力测试（校内组织）+ 中文素养面试（考察传统文化理解）
  • 特色课程：《三星堆与世界文明》《都江堰工程哲学》双语课程，海外研学覆盖牛津、早稻田、新加坡国立大学
  • 升学成果：2024届92%进入QS前50大学，其中剑桥、耶鲁、东京大学录取17人。
