阳光招生 · 公平公正

招生类型

  • 普通高考（含国家专项、高校专项、民族班）
  • 高水平艺术团 / 运动队（已暂停，2025年不招生）
  • 港澳台侨联招 / 对台单招
  • 国际学生（英文授课本科项目）

录取规则

  • 平行志愿省份：专业志愿“分数优先”，无级差
  • 非平行志愿省份：专业志愿“志愿优先”，按投档分排序
  • 同分排序：依次比较数学、外语、语文成绩
  • 英语专业要求外语语种为英语，口试合格

特色培养

  • 茅以升班：本硕贯通，导师制，保研率≥80%
  • 詹天佑班：面向国家战略需求，小班化、项目制
  • 国际化示范学院：与英国利兹大学合办“交通运输”双学位
  • 微专业计划：开放“智能建造”“碳中和”等12个微专业
